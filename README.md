# Railway Management System

## Description
A Railway Management System developed using Python, Tkinter and MySQL. This application helps manage train details, passenger records and ticket booking through a user-friendly desktop interface.

## Features
- Login System
- Train Management
- Passenger Management
- Ticket Booking
- MySQL Database Integration

## Technologies Used
- Python
- Tkinter
- MySQL

## Project Structure
- login.py
- dashboard.py
- train.py
- passenger.py
- ticket.py
- database.py
- config.py

## How to Run
1. Install Python.
2. Install MySQL.
3. Configure database settings in `config.py`.
4. Run `login.py`.
